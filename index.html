কেন রক্তদান করবেন?

স্বেচ্ছায় রক্তদানের শারীরিক ও মানসিক কিছু বড় সুবিধা

হৃদরোগের ঝুঁকি কমায়

নিয়মিত রক্তদানে শরীরে অতিরিক্ত আয়রনের মাত্রা নিয়ন্ত্রণে থাকে, যা হৃদযন্ত্র সুস্থ রাখে।

নতুন রক্তকণিকা সৃষ্টি

রক্তদানের পর অস্থিমজ্জা খুব দ্রুত নতুন লোহিত রক্তকণিকা তৈরি শুরু করে।

আত্মিক মানসিক শান্তি

একজন মুমূর্ষু রোগীর প্রাণ বাঁচানোর সুযোগ মানুষের মানসিকভাবে আত্মতৃপ্তি এনে দেয়।

উপকারভোগীদের কথা

সাহায্য পাওয়ার অভিজ্ঞতা ও কৃতজ্ঞতা

এই ক্লাবের মাধ্যমে জরুরি মুহূর্তে রক্তের ব্যবস্থা হয়ে যারা উপকৃত হয়েছেন, তাদের মন্তব্য।

অনুমোদিত রক্তদাতা ডিরেক্টরি

প্রয়োজনীয় গ্রুপের রক্তদাতা অনুসন্ধান করুন। (শুধুমাত্র অ্যাডমিন অনুমোদিত সক্রিয় ডোনারগণ প্রদর্শিত হচ্ছেন)

রক্তদাতা নিবন্ধন ফর্ম

আবেদনটি জমা দেওয়ার পর অ্যাডমিন প্যানেল থেকে যাচাইকরণের মাধ্যমে আপনার প্রোফাইলটি ডিরেক্টরিতে প্রকাশিত হবে।

তথ্য সম্পর্কিত সতর্কতা:

নিবন্ধনের মাধ্যমে আপনি সম্মতি দিচ্ছেন যে, প্রয়োজনে রক্তপ্রার্থীরা এই মোবাইল নম্বরে যোগাযোগ করতে পারবে। তথ্য সম্পূর্ণ সঠিক প্রদান করুন।

Database Schema & SQL Script View

Supabase বা PostgreSQL ব্যাকএন্ডে এই ওয়েবসাইটের ডাটাবেজ তৈরি করার জন্য রেডিমেড SQL ব্লুপ্রিন্ট।

কেন এই SQL স্কিমাটি ব্যবহার করবেন?

  • স্বয়ংক্রিয় টেবিল গঠন: ডোনার নিবন্ধিত তালিকা, রক্তদান যাচনা এবং অডিট লগ করার নিখুঁত টেবিল ফরম্যাট।
  • নিরাপত্তা রুলস (RLS): সাধারণ ইউজাররা কেবল Approved রক্তদাতাই দেখতে পারবে, কিন্তু Pending আবেদনের জন্য অ্যাডমিন রুল কার্যকর থাকবে।
  • কপি ব্যাকএন্ড কোড: আপনার ক্লাউড ডাটাবেজ কন্সোলে SQL কোড কপি ও রান করে মুহূর্তেই ডাটাবেজ অ্যাক্টিভ করতে পারবেন।
-- Create Donors Table with Pending/Approved Flow
CREATE TABLE donors (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    full_name VARCHAR(100) NOT NULL,
    blood_group VARCHAR(5) NOT NULL,
    phone VARCHAR(20) NOT NULL,
    location VARCHAR(100) NOT NULL,
    category VARCHAR(50) NOT NULL,
    last_donation_date DATE,
    status VARCHAR(20) DEFAULT 'Pending' CHECK (status IN ('Pending', 'Approved', 'Rejected', 'Inactive')),
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Create Blood Requests Table
CREATE TABLE blood_requests (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    patient_name VARCHAR(100) NOT NULL,
    blood_group VARCHAR(5) NOT NULL,
    units INTEGER DEFAULT 1,
    hospital VARCHAR(150) NOT NULL,
    contact_number VARCHAR(20) NOT NULL,
    needed_date DATE NOT NULL,
    status VARCHAR(20) DEFAULT 'Verified' CHECK (status IN ('Pending', 'Verified', 'Fulfilled', 'Cancelled')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Row Level Security Rules
ALTER TABLE donors ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public Approved Donors View" ON donors FOR SELECT USING (status = 'Approved' AND is_active = true);
